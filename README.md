# 璟松 JING SONG

> 為自己而旅行 — 全球精緻深度旅遊個人品牌

## 內容

| 檔案 | 說明 |
|------|------|
| `index.html` | 品牌官網（單頁式 Landing Page） |
| `itinerary.html` | 行程規劃系統（資料存瀏覽器本機，可列印、可備份） |
| `assets/brand.png` | 品牌識別系統圖 |

## 本機開啟

直接雙擊 `index.html` 即可，無需安裝任何環境。

## 行程系統使用

- **新增旅程**：左側「＋ 新增旅程」，填名稱、目的地、日期，自動依天數建立每日欄位
- **加行程**：每天下方「＋ 加入行程項目」，可填時間、景點、地點、備註，依時間自動排序
- **匯出備份**：右上「匯出備份」存成 JSON 檔（建議定期備份，資料存在瀏覽器本機）
- **列印 / PDF**：右上「列印 / 存 PDF」，自動套用精緻列印版型

## 部署

純靜態網站，可部署至 GitHub Pages、Vercel、Netlify 等任一平台。詳見 `DEPLOY.md`。
